A three variable log linear model can be expressed as the following : 
$$ lnY_i = B_1 + B_2lnX_{2i} + B_3lnX_{3i} + u_i $$
1. in this model the partial slope coefficients are also called the partial elasticity coefficient. 
2. Thus, B2 measures the elasticity of Y with the respect of X2, holding the influence of X3 constant, since the influence of X3 is held constant it is called a partial elasticity. 
3. similarly the B3 measures the partial elasticity of Y with respect to X3, holding the influence of X2 constant. 

> in short in a multiple log linear model, each partial slope coefficient measures the partial elasticity of the dependent variable with respect to the explanatory variable in question, holding all other variables constant. 

1. if we add the elasticity coefficients, we obtain the returns to scale parameter. 
2. if the sum of the elasticity coefficient turns out to be 1 we say a constant returns to scale, if it is greater than 1 we say an increasing returns to scale and if it is lower than 1, we say a decreasing returns to scale.
