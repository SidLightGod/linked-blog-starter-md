1. the models of the following type are known as the reciprocal models $$ Y_i = B_1 + B_2(\frac{1}{X_i}) + u_i $$
2. this model is nonlinear in X because it enters the model inversely or reciprocally but it is a linear regression model because the parameters are linear 
3. the salient feature of this model is that X increases indefinitely, the term $\frac{1}{X_i}$ approaches zero as Y approaches the limiting or asymptotic value of B1. 
4. therefore these kind of models have built into them an asymptote or limit value that the dependent variables will take when the value of X variable increases indefinitely. 

> an important aspect about this model is that the slope coefficient in this model behaves differently. Meaning that a negative slope coefficient here would imply a positive relation between Y and X and a positive slope coefficient would imply a negative relation between Y and X. so a negative slope here is the same as a positive slope for a linear in variable model.
