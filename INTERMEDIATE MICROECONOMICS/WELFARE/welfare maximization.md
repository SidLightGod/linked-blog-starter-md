1. if we have total amount X1,......Xk of good 1,.....,K to distribute among the consumers, we can pose the welfare maximization problem : $$ max \space W(u_1(x),....,u_n(x) ) $$ such that $$ \sum_{i=1}^n x_i^1 = X^1 $$ => $$  \sum_{i=1}^n x_i^k = X^k $$
2. thus we are trying to find the feasible allocation that maximizes the social welfare 

###### what properties does such an allocation have?
1. the first thing to be noted is that a maximal welfare allocation must be a pareto efficient allocation. 
2. then there would be some other feasible allocation that gave everyone at least as large a utility, and someone strictly greater utility. 
3. But the welfare function is a strictly increasing function of each agent's utility. Thus this new allocation would have to have higher welfare, which contradicts the assumption that we originally had a welfare maximum.
